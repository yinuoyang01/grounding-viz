v44 rollout arenas — the 7 datasets we roll Molmo2-4B out on
v44 pairs come from REAL rollouts judged against these datasets' GT (we do not reuse their synthetic point strings). First batch: 16,000 prompts x 8 samples = 128k rollouts; max 1 prompt/image, train splits only, banned_images_v44 filter. GT overlays below: pink filled circles = GT points (numbered), green rectangle = GT element bbox.

pixmo_points_train — pixmo_datasets/points-pointing — 152,858 train images

GT = per-label point lists (x,y in 0-100); prompt "point to all <label>". Core natural-image pointing, matches the GRPO distribution.
prompt: point to all bendable part of leg midway — GT: 4 point(s), x/y in 0-100 of image size
prompt: point to all orange petals — GT: 5 point(s), x/y in 0-100 of image size
prompt: point to all Talons — GT: 4 point(s), x/y in 0-100 of image size

pixmo_points_high_freq — pixmo_datasets/points-counting — 70,714 train images

GT = dense per-label point lists + count (0-100 coords); the "counting" collection_method subset (naming inverted). Multi-point regime, ~10+ instances/label.
prompt: point to all eyes — GT: 39 point(s), x/y in 0-100 of image size
prompt: point to all plastic figure — GT: 100 point(s), x/y in 0-100 of image size
prompt: point to all beads — GT: 99 point(s), x/y in 0-100 of image size

pixmo_count — pixmo_datasets/count — 36,916 train rows

GT = single label + integer count (+ points when count>0, 0-100 coords); count=0 rows are free abstain prompts.
prompt: count the people — GT count = 6
prompt: count the people — GT count = 5
prompt: count the people — GT count = 10

cosyn_point — pixmo_datasets/cosyn-point — 68,051 train images (~5 questions each)

Synthetic rendered docs/UIs; GT = per-question answer point(s) in 0-100, exact by construction (renderer).
question: Find the specific resource dedicated to actors' mental health support. — target: Actors Support Program, 1 GT point(s) in 0-100
question: Find the footer elements containing both the text and the blog link. — target: Footer Elements, 2 GT point(s) in 0-100
question: Show me both the live match indicators for the ongoing games. — target: Live Match Indicators, 1 GT point(s) in 0-100

molmo2_syn_point (GUISyn) — allenai/MolmoPoint-GUISyn — 36,192 HF train images; extracted RL prompts: 144,290 element-intent rows

GT = element bbox (center+w/h, px); parquet ground_truth = centroid in 0-999; judge point-in-bbox. Subsets desktop/mobile/web.
[desktop] prompt: Point to: Open the C drive by clicking it in the sidebar — GT = element centroid (0-999 coords; judge point-in-bbox)
[mobile] prompt: Point to: Select the translated text to copy or share it — GT = element centroid (0-999 coords; judge point-in-bbox)
[web] prompt: Point to: Decrease the chicken breast quantity — GT = element centroid (0-999 coords; judge point-in-bbox)

synthetic_ground_point — webolmo_synthetic_ground — 466,599 train screenshots / 4.1M clickable elements, 23 websites

GT = element bbox [x,y,w,h] in px (image == viewport); prompt = GPT-5 query per element; judge point-in-bbox.
[amazon] GPT-5 query: read all reviews — GT = element bbox (px), element: link '12,325 Reviews'
[allrecipes] GPT-5 query: read the Privacy Policy — GT = element bbox (px), element: link 'Privacy Policy'
[wikipedia] GPT-5 query: open citation 39 — GT = element bbox (px), element: link '[39]'

ground_cua — GroundCUA/formatted_data.json — 3,131,480 records / 50,492 unique screenshots (desktop apps)

GT = element bbox in 0-100 (metadata.bbox); the stored click answer is a gaussian sample inside it — judge point-in-bbox, not the click.
[Audacity] question: Click on the element that matches the description: element with content: Tracks menu — GT = element bbox (green, 0-100 coords); pink dot = pre-sampled click (gaussian in bbox; judge uses the bbox)
[Audacity] question: Click on element that says Recording metre . — GT = element bbox (green, 0-100 coords); pink dot = pre-sampled click (gaussian in bbox; judge uses the bbox)
[Bitwarden] question: Click on the element that matches the description: an element that contains Vaults — GT = element bbox (green, 0-100 coords); pink dot = pre-sampled click (gaussian in bbox; judge uses the bbox)
